What YOU still need to do
-------------------------

1. Deploy the updated backend to Google Apps Script
   - The latest backend/Code.gs is in this project.
   - Open your Google Apps Script project or use clasp.
   - Paste / deploy the new Code.gs as a version.
   - Run setupScheduledTriggers() once from the Apps Script editor and confirm a five-minute trigger exists.
   - Make sure the script properties are still set:
     SPREADSHEET_ID, ADMIN_PASSWORD_HASH, TWILIO_*, FCM_*, PUBLIC_APP_URL,
     CLOUDINARY_*, SECURE_LINK_SECRET, SMS_ENABLED, ADMIN_SETUP_TOKEN,
     ADMIN_RECOVERY_TOKEN, DRIVER_SETTLE_FEE_PER_JOB, DRIVER_SETTLE_WEEKLY_CAP

2. Complete internal release-candidate testing
   - Install the latest uniquely named release-candidate APK on Android 11, 13 and 15 where possible.
   - Test customer registration, booking, cancellation and live tracking.
   - Test driver login, background location, offers, navigation, arrival PIN and completion.
   - Test SMS and push delivery, future bookings, airport returns and no-show evidence.

3. Create / open Google Play Console
   - Go to https://play.google.com/console
   - Pay the $25 one-time developer fee.
   - Create a new app called "Wirral Jobe".

4. Upload the AAB to Play Console
   - In Play Console, go to Testing > Internal testing or Closed testing.
   - Upload the final signed AAB from _DELIVERABLES.
   - Confirm its version code is higher than every build previously uploaded to Play Console.

5. Fill in the store listing
   - App name: Wirral Jobe
   - Short description: see PLAY_STORE_LISTING.txt
   - Full description: see PLAY_STORE_LISTING.txt
   - Privacy policy URL: https://wirraljobe.com/privacy
   - App icon: _STORE_ASSETS/play_store_icon_512.png
   - Feature graphic: _STORE_ASSETS/feature_graphic_1024x500.png
   - Phone screenshots: take 2-8 screenshots on a phone (real or emulator)
   - Content rating: answer the questionnaire

6. Submit for review
   - Pick countries (start with UK only).
   - Complete the data safety form for precise/background driver location,
     phone number, name, optional email, booking data, app activity and device tokens.
   - Declare Twilio, Firebase/Google, Mapbox, Netlify and Google Apps Script processing.
   - Complete the Background Location and Foreground Service declarations.
   - Submit to production after internal testing looks good.

Notes
-----
- The release keystore is android/app/wirraljobe.keystore. Keep its passwords only in a secure password manager or protected CI/hosting secrets, never in the repository or deliverables.
- If Play App Signing is already active with a different upload key, follow the Play Console upload-key reset process before uploading.
- Restrict the public Mapbox and Google browser keys to the production app/site where supported.
